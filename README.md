# WebLoom

WebLoom captures publicly accessible website frontends into organized, previewable projects.

## Stack

- Flask / Python
- Supabase Auth, Postgres, and Storage
- Stripe subscriptions
- Vercel deployment

## Local development

```bash
python -m pip install -r requirements.txt
python web_app.py
```

Public pages only. WebLoom does not bypass authentication, paywalls, CAPTCHA, DRM, or other access controls.
