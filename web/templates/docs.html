{% if section == 'start' %} WebLoom Docs

Public web data and frontend reconstruction, one API.

WebLoom combines a reconstructed frontend capture with Fusion data outputs: clean Markdown, structured entities, link graphs, change fingerprints and passive technical metadata.

CloneCapture reachable public frontend files into a previewable project and ZIP.
ScrapeTurn one public page into clean Markdown, metadata and structured entities.
CrawlFollow public internal pages and return an AI-ready page dataset.
FusionRun crawl + graph + change tracking + passive frontend analysis together.

Quick start

Create an API key from API keys, then send it as a Bearer token.

curl -X POST https://YOUR_WEBLOOM_DOMAIN/v1/scrape \ -H "Authorization: Bearer wl_YOUR_KEY" \ -H "Content-Type: application/json" \ -d '{"url":"https://example.com"}'
Public web only.

WebLoom does not bypass authentication, CAPTCHA, paywalls, DRM or private network boundaries.

Capture outputs

Completed projects can contain webloom-project.json, metadata.json, links.json, sitemap.xml, fusion.json, dataset.jsonl, knowledge_base.md, graph.json, audit.json, plus the reconstructed frontend files.

{% elif section == 'api' %} API Reference

Five endpoints. One consistent web-data surface.

Authenticate using Authorization: Bearer wl_.... Scrape and Map are lightweight; Crawl, Extract and Fusion are Pro operations.

Endpoints

POST/v1/scrapeOne page → Markdown + entities
POST/v1/mapDiscover URLs
POST/v1/crawlMulti-page dataset
POST/v1/extractNamed structured fields
POST/v1/fusionFull graph + data + audit

Scrape

{ "url": "https://example.com" }

Returns clean Markdown, metadata/entities, link sets, change fingerprint and passive page audit information.

Crawl

{ "url": "https://example.com", "limit": 50, "max_depth": 2 }

Extract

{ "url": "https://example.com", "fields": ["title", "description", "author", "canonical"], "limit": 20 }

Fusion

{ "url": "https://example.com", "limit": 50, "max_depth": 2 }

Returns the Fusion manifest, page records and downloadable artifact contents. Public client-side audit findings redact credential-like values.

OpenAPI

The machine-readable specification is available at /v1/openapi.json.

{% else %} MCP

Give AI agents WebLoom tools directly.

The WebLoom MCP server exposes scrape, map, crawl, extract and fusion as read-only public-web tools backed by your WebLoom API key.

Install from this repository

cd mcp-server npm install

Client configuration

{ "mcpServers": { "webloom": { "command": "node", "args": ["/absolute/path/to/webloom/mcp-server/src/index.mjs"], "env": { "WEBLOOM_API_URL": "https://YOUR_WEBLOOM_DOMAIN", "WEBLOOM_API_KEY": "wl_YOUR_KEY" } } } }

Tools

webloom_scrapeScrape one known public URL.
webloom_mapDiscover URLs before deciding what to crawl.
webloom_crawlCollect clean content across a site.
webloom_extractExtract named metadata/schema fields.
webloom_fusionReturn the complete Fusion dataset and graph.
Safety boundary.

The MCP server is designed for public-web reading and extraction. It does not provide login bypass, CAPTCHA bypass or authenticated exploitation.
